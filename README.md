# Employee Pay Calculator

## Description

This Python program calculates an employee’s:

* Gross income
* Taxes
* Deductions
* Net pay

The calculations are based on hourly pay, hours worked, and optional program enrollments.

---

## Features

* Input validation
* Function-based calculations
* Tax calculation (12%)
* Optional deductions:

  * Charity Program ($0.50)
  * Celebrations Program ($1.00)

---

## Requirements

* Python 3.x
